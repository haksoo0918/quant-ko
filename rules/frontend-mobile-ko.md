# 프론트엔드 및 모바일 개발 규칙 (Frontend & Mobile Standards)

본 문서는 UI/UX 개발 원칙, 디자인 일관성 유지 및 클라이언트 구현 표준을 정의합니다.

## 1. 화면 우선 및 Mock 우선 워크플로우

1. **백엔드 연동 전 화면 선검증**:
   - UI 중심 작업 시 백엔드 API 연동에 앞서 목(Mock) 데이터를 활용해 화면 레이아웃과 사용자 인터랙션을 먼저 검증합니다.
   - 빈 화면(Empty), 로딩(Loading), 오류(Error), 부분 데이터 상태를 사전에 설계하고 확인합니다.
2. **신속한 프로토타이핑**:
   - UI 탐색 단계에서는 인메모리 상태나 픽스처(Fixture) 데이터를 활용해 빠른 피드백 루프를 만듭니다.
   - 레이아웃과 사용성이 사용자 의도와 일치하는지 확인한 후 데이터 통신 로직을 결합합니다.

---

## 2. 컴포넌트 아키텍처 및 디자인 일관성

1. **단일 책임 원칙**: 컴포넌트는 작고 독립적이며 재사용 가능하도록 모듈화합니다.
2. **프레젠테이션과 비즈니스 로직 분리**: 화면 렌더링에 집중하는 순수 UI 컴포넌트와 데이터 통신 및 상태를 제어하는 컨테이너/훅을 분리합니다.
3. **Headless UI 컴포넌트 적극 활용**:
   - 웹 접근성(a11y)과 키보드 내비게이션이 내장된 Headless UI 프리미티브(예: Radix UI, Reka UI 등)를 적극 도입합니다.
   - 동작과 접근성은 프리미티브에 위임하고, 비주얼 스타일은 순수 모던 CSS로 직접 제어합니다.
4. **순수 모던 CSS 표준 준수 (Native Modern CSS)**:
   - 외부 프레임워크나 서드파티 유틸리티 없이, 브라우저 표준 모던 CSS(`@layer`, `@container`, CSS 변수 등)를 직접 활용합니다.
5. **디자인 토큰 활용**:
   - 색상, 폰트 크기, 여백(Spacing), 그림자 등은 미리 정의된 디자인 토큰(CSS 변수 등)을 일관되게 사용합니다.
   - 코드에 임의의 하드코딩된 스타일(매직 넘버)을 남기지 않습니다.

---

## 3. 모바일 퍼스트 반응형 및 접근성 (a11y)

1. **모바일 퍼스트 (Mobile-First)**:
   - 모바일 화면(<640px)을 기본으로 설계·구현하고, `min-width` 브레이크포인트로 점진 확장(데스크톱 스타일 역방향 오버라이드 금지).
   - 대화형 요소의 최소 터치 타깃(44×44px 이상) 확보 및 가로 스크롤 방어 레이아웃 적용.
2. **시맨틱 마크업 & 키보드 탐색**:
   - 시맨틱 HTML 태그(`<header>`, `<nav>`, `<main>`, `<button>` 등)와 텍스트 없는 대화형 요소에 `aria-label` 필수 제공.
   - WCAG AA 기준의 명도 대비와 명확한 키보드 포커스 링 유지.
3. **색약/색맹 접근성 배려**:
   - 상태(성공, 경고, 오류)나 정보를 색상만으로 전달하지 않으며 라벨, 아이콘, 테두리 패턴 등을 병행.
   - 차트·시각화에 명도차, 대조 패턴(해시/점선), 직접 범례 활용 및 적록 단독 대비 지양(블루/오렌지 등 안전 팔레트 권장).

---

## 4. 현대적 CSS 스타일링 표준 (Modern CSS)

1. **컴포넌트 쿼리 (@container)**: 전역 뷰포트 미디어 쿼리보다 컴포넌트 단위 반응성을 위한 `@container` 우선 적용.
2. **캐스케이드 레이어 (@layer)**: 명시도 충돌 방지를 위해 `@layer reset, base, components, utilities` 구조 내 배치.
3. **네이밍 컨벤션 (kebab-case)**:
   - 클래스명: 영문 소문자 `kebab-case` 사용 (예: `.card-header`, `.btn-primary`).
   - CSS 변수(토큰): `--카테고리-속성-상태` 계층형 `kebab-case` 사용 (예: `--color-bg-primary`, `--space-md`).
4. **디자인 토큰 & CSS 변수**: `:root` 전역 토큰과 컴포넌트 스코프 로컬 변수 패턴 적용.
5. **최신 CSS 네이티브 기능**: 중첩(`&`), 관계형 선택자(`:has()`), Subgrid, 수학 함수(`clamp()`, `min()`, `max()`) 적극 활용.

---

## 5. 성능 및 코어 웹 바이탈 (CWV)

1. **에셋 최적화**: WebP/AVIF 최신 포맷 사용, 이미지 가로/세로 크기 명시로 CLS 방지.
2. **코드 분할 (Code Splitting)**: 라우트별 지연 로딩으로 초기 로딩 속도(LCP) 및 반응성(INP) 확보.
